# Paper Assets

This directory contains the LaTeX source and generated figures/tables for the ECSafeBench-CN manuscript.

- `main.tex`: main manuscript source.
- `references.bib`: bibliography.
- `neurips_2026.sty`: local NeurIPS-style preprint template used for drafting.
- `figures/`: graphical abstract and paper figures in PDF/PNG formats.
- `tables/`: compact LaTeX table snippets and analysis CSVs used by the manuscript.

The compiled paper PDF is also stored at the repository root.
